## 运行采样

同一台电脑、同一份 Mod 状态，程序出现窗口并进入消息循环后等待 3 秒，采样内存与累计 CPU 时间，再正常退出。连续启动各 3 次，表格取中位数。

| 项目 | v0.1.1 | v0.1.2 |
| --- | ---: | ---: |
| 工作集 | 116.47 MiB | 118.93 MiB |
| 私有内存 | 75.23 MiB | 73.06 MiB |
| 窗口出现时间 | 757 ms | 783 ms |
| 累计 CPU | 812.5 ms | 1,093.75 ms |

原始样本依序如下：

| 版本 | 窗口 ms | 工作集字节 | 私有内存字节 | 累计 CPU ms |
| --- | --- | --- | --- | --- |
| v0.1.1 | 1275 / 757 / 757 | 140935168 / 122130432 / 122015744 | 92467200 / 78888960 / 77303808 | 1718.75 / 812.5 / 796.875 |
| v0.1.2 | 783 / 780 / 831 | 124710912 / 121872384 / 140013568 | 75718656 / 76611584 / 90083328 | 1093.75 / 750 / 1500 |

这些数值代表本机样本，受游戏运行、编译与系统负载影响；本轮确认的是窗口和分发体积缩小，没有证明运行速度或工作集进一步改善。新 EXE 在打包器运行期间首次启动另测得 11,457 ms，不计入重复启动对比。
