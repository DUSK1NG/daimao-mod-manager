## 改动

- 打包时从原始画像生成三张 204×204 PNG，供 68 DIP 的界面画像使用，覆盖到 300% 缩放。原始素材继续保留；EXE 不再嵌入没有使用的大图。
- 内置 7-Zip 通过流进行校验和释放，避免完整组件的多份字节数组。主窗口与安装核心共用 ArchiveService，启动只检查一次工具缓存。
- 冲突预览建立路径索引，安装冲突查询使用字典，减少按每个文件反复遍历整个列表。
- 仅管理员辅助进程操作完成后重新读取状态，普通启停直接使用核心已更新的状态；合并重复的权限异常处理，移除重复去重与一次原文件哈希读取。
- 操作记录保留本次运行最近 200 条，避免长时间使用后持续增长。游戏进程查询所得的 Process 对象及时释放。
- 修复旧包有独有文件时无法切换到新包的问题：恢复覆盖前的文件，撤回旧包新增文件，再持久保存启停状态。

路径检查、缓存完整性校验、外部修改检测、覆盖前备份、跨进程锁和中断恢复仍保留。

## 验证与复测

23 项核心集成测试通过，包含真实 RAR 和多版本 ZIP 的导入、启用、停用。新增测试覆盖冲突切换中旧包独有文件的恢复。WPF 测试覆盖四种窗口尺寸、画像尺寸与冻结状态、界面启停后的文件及列表状态、大小写不敏感的冲突预览，以及内置工具缓存的首次释放、复用、损坏修复和缺失补齐。完整解决方案构建为零警告、零错误。
