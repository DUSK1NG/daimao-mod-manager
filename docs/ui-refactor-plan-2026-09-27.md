# WPF 界面重构计划

## 目标与边界

将现有 Antigravity WPF 界面整理成清楚、耐看的三作 Mod 管理器。保留游戏选择、目录浏览、拖拽导入、版本选择、手动映射、Mod 启停、前置配置、操作记录及原有安全提示。只改界面与必要的布局逻辑，不改变 Core 的安装事务。

资源目标是沿用系统 WPF 控件和矢量几何，不引入第三方 UI 库、位图素材、模糊、阴影或持续动画。以同机空闲工作集对比作为参考，不把一次测量当作跨设备保证。

## 设计与实施顺序

1. **整理视觉系统。** 用深石板底色、暖金色主操作和青绿色成功状态建立克制的狩猎工具风格。统一字体、间距、圆角、焦点与禁用状态；减少纯装饰元素。
2. **重排主界面。** 顶部提供标题、游戏切换和目录；左侧为可勾选的 Mod 列表及数量/空状态；右侧的导入、前置、记录保持原功能。导入页突出拖拽区、深色版本列表与明确的“导入后默认停用”按钮；手动映射收在高级选项内，让文件预览获得更多空间。
3. **处理小窗口与缩放。** 常规宽度采用左右分栏，窄窗缩小左栏并让右侧表单滚动；限制启动位置和尺寸在屏幕可用区域内，确保选择按钮、导入按钮、列表与状态栏可见。
4. **验证。** 在新 WPF 项目上编译并运行原有 Core/WinForms 测试；实机检查约 800×760、1100×760 和 640×540 的布局与主要操作控件，记录截图和空闲内存。只读打开归档预览，不向游戏目录写入。

## 验收

- 不改变导入、启停、前置配置的 ViewModel 命令和数据流；主要控件在窄窗仍可操作。
- 空列表、未选压缩包和已有 Mod 三种状态的信息层级清楚，中文文本不出现明显裁切。
